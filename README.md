Neste projeto, a ideia era desenvolver um sistema para validação de senhas com as seguintes funcionalidades:
-Regras de Senha:
A senha deve conter no mínimo 8 caracteres.
Deve incluir obrigatoriamente:
Letras maiúsculas;
Letras minúsculas;
Números;
Pelo menos um caractere especial (ex: !, @, #, $, %, etc.).

-Regras de Troca de Senha:
O sistema deve obrigar a troca de senha a cada 45 dias;
O usuário não poderá reutilizar nenhuma das últimas 7 senhas;

-Funcionalidades esperadas:
Tela de cadastro de novo usuário com validação da senha;
Tela de login com autenticação básica;
Lógica de verificação da expiração da senha (45 dias);
Lógica para armazenamento e verificação das últimas 7 senhas utilizadas;
Armazenamento de dados pode ser feito com Banco de Dados.

Para a realização deste projeto utilizei a linguagem Java, framework Swing, juntamente com o banco de dados MySQL Workbench e servidor Xampp. A IDE utilizada foi o NetBeans Projects.
